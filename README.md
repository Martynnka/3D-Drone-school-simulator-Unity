# Drone Training Game

Unity 3D drone flying game focused on training, freestyle flying,
and progression-based unlocks.

## Status
Work in Progress

## Current Features
- Drone movement 
- Main Map
- Main Menu
- Computer Menu (Start Drone Flight, Controls, Turn Down button, credits panel.)
- Player movement
- Training area


## Planned Features
- Drone unlock system
- Mini rank system
- Coins system
- ESC Menu

## Controls
Movement:
Throttle — W
Strafe Left — A
Strafe Right — D
Ascend — Z
Auto-Level — X

Rotation:
Pitch Up — Space
Pitch Down — Shift
Roll Left — Q
Roll Right — E
Quit Drone mode - P

Player Movement:
Forward - W
Backward - S
Right - D
Left - A
Jump - Space

- Unity 3D
