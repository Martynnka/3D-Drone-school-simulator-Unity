# Drone Training Game

Unity 3D drone flying game focused on training, freestyle flying,
and progression-based unlocks.

## Status
Work in Progress

## Current Features
- Drone/player movement
- Training map
- Main Menu

## Planned Features
- Second freestyle map
- Drone unlock system
- UI
- Mini rank system
- Coins system

## Controls
- WASD – move
- Space / Ctrl – up / down
- R – reset drone

## Tech
- Unity 3D
- C#
