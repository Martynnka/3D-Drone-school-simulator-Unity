# Drone Training Game

Unity 3D drone flying game focused on training, freestyle flying,
and progression-based unlocks.

## Status
Work in Progress

## Current Features
- Drone movement 
- Main Map
- Main Menu

## Planned Features
- Player movement
- Second freestyle map
- Drone unlock system
- UI
- Mini rank system
- Coins system

## Controls
Movement:
Throttle — W
Strafe Left — A
Strafe Right — D
Ascend — Z
Auto-Level — X

Rotation:
Pitch Up — Space
Pitch Down — Shift
Roll Left — Q
Roll Right — E

## Tech
- Unity 3D
- C#
